# Google Keep Clone

A simple Google Keep-style clone made with HTML, CSS and JavaScript.

## Base Project

The project includes:

- Google Keep-style navigation bar
- Keep logo
- Menu/sidebar
- Notes
- Reminders menu
- Edit labels menu
- Archive
- Trash
- Search
- Refresh button
- Profile placeholder
- Create notes
- Delete notes
- Archive notes
- Masonry-style notes grid
- Responsive desktop, tablet and mobile layout
- localStorage

## Manual Custom Feature

### Colour-coded notes

Users can choose a colour when creating a note.

Available colours:

- Default
- Yellow
- Green
- Blue
- Pink
- Purple

The selected colour is saved with the note using localStorage.

## Cursor Features

The following features have intentionally not been added yet:

1. Reminders
2. Drag-and-drop note reordering

These will be added using Cursor for the assignment.

Open `index.html` in a browser.
